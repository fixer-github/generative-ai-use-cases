## 検証結果サマリー

### ✅ 正常に動作している項目
1. Webhookエンドポイントの設定
2. Lambda関数へのリクエスト到達
3. テナントIDの識別
4. Lambda関数の環境変数設定

### ❌ 問題が検出された項目
1. **署名検証処理が完了していない**
   - 証拠: 「Stripe signature verified successfully」ログが出力されていない
   - 影響: 以降の処理（イベント保存、EventBridge送信）が実行されない

2. **Webhookイベントがデータベースに保存されていない**
   - 証拠: DynamoDBテーブルが空
   - 影響: 重複チェックが機能しない、イベント履歴が記録されない

3. **EventBridgeへのイベント送信が行われていない**
   - 証拠: Orchestration Lambda関数のログが存在しない
   - 影響: ビジネスロジック（サブスクリプション情報の保存、プラン権限の付与）が実行されない

4. **Stripeへの正常応答が返されていない**
   - 証拠: イベントの `pending_webhooks` が 1 のまま
   - 影響: Stripeが再送を試みる可能性

### 処理の停止箇所の特定

コード解析（[receiveWebhook.ts:82-91](../../packages/cdk/lambda/billing/payment-gateway/webhook/stripe/receiveWebhook.ts#L82-L91)）より、以下のチェックポイントで処理が停止している可能性：

```typescript
// 3. リクエストボディと署名を取得
const payload = event.body;
const signature = event.headers['stripe-signature'];

if (!payload || !signature) {
  return {
    statusCode: 400,
    body: JSON.stringify({ error: 'Missing payload or signature' }),
  };
}
```

**推測される原因:**
- `event.headers['stripe-signature']` が `undefined` または `null`
- API Gatewayでのヘッダーマッピングに問題がある可能性
