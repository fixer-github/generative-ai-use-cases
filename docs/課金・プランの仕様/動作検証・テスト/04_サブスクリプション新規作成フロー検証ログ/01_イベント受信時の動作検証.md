### ❌ 新たに発見された問題

#### 問題1: `customer.subscription.created`イベントがビジネスイベントにマッピングされていない

**現象:**
```
INFO Event type customer.subscription.created is not mapped to business event. Skipping EventBridge send.
```

**原因:**
- [eventMapper.ts](../../../packages/cdk/lambda/billing/payment-gateway/webhook/stripe/eventMapper.ts)の`STRIPE_TO_BUSINESS_EVENT_MAP`に`customer.subscription.created`のエントリが存在しない
- そのため`mapStripeEventToBusinessEvent()`がnullを返し、EventBridge送信がスキップされる

**影響:**
- サブスクリプション新規作成時のビジネスイベントがEventBridgeに送信されない
- 後続の統括責務側でユーザー権限の更新などが実行されない

**修正が必要な箇所:**
- [eventMapper.ts](../../../packages/cdk/lambda/billing/payment-gateway/webhook/stripe/eventMapper.ts)に`'customer.subscription.created': 'subscription.created'`のマッピングを追加
- [eventExtractor.ts](../../../packages/cdk/lambda/billing/payment-gateway/webhook/stripe/eventExtractor.ts)に`customer.subscription.created`イベントからの情報抽出関数を追加

#### 問題2: `invoice.payment_succeeded`イベントで`subscriptionId`の抽出に失敗

**現象:**
```
ERROR Failed to extract event details: Error: subscriptionId is required but not found in invoice.payment_succeeded event
```

**原因:**
- Stripe CLIの`trigger`コマンドで生成されたテストイベントでは、invoiceオブジェクトに`subscription`フィールドが含まれていない可能性がある
- [eventExtractor.ts:46-50](../../../packages/cdk/lambda/billing/payment-gateway/webhook/stripe/eventExtractor.ts#L46-L50)の抽出ロジックがテストイベントのデータ構造に対応していない

**影響:**
- `invoice.payment_succeeded`イベントのEventBridge送信時にエラーが発生し、処理が中断される
- サブスクリプション作成後の初回支払い成功イベントが後続処理に伝播しない

**修正が必要な箇所:**
- Stripe CLIのテストイベントペイロードを詳細調査し、`subscription`フィールドの有無を確認
- 必要に応じて、テストイベント用のフォールバックロジックを追加

```typescript
function extractFromSubscriptionCreated(
  stripeEvent: Stripe.Event,
  tenantId: string
): Partial<EventDetail> {
  const subscription = stripeEvent.data.object as Stripe.Subscription;

  return {
    platform: 'stripe',
    tenantId,
    eventId: stripeEvent.id,
    originalEventType: stripeEvent.type,
    subscriptionId: subscription.id,
    userId: subscription.metadata?.userId || '',
    planId: subscription.items.data[0]?.price?.id || '',
    expirationDate: new Date(subscription.current_period_end * 1000).toISOString(),
    eventData: stripeEvent,
  };
}
```

2. 修正後、再度Stripe CLIでテストイベントをトリガーし、全フローの動作を確認
