## データの読み取り操作

### 商品一覧の取得
```bash
stripe products list --limit 5
```

### 価格一覧の取得
```bash
stripe prices list --limit 5
```

### 顧客一覧の取得
```bash
stripe customers list --limit 5
```

### サブスクリプション一覧の取得
```bash
stripe subscriptions list --limit 5
```

### イベント履歴の取得
Stripe上で発生したイベント（Webhook送信対象）の履歴を確認できます。

**全イベントの取得:**
```bash
stripe events list --limit 10
```

**特定のイベントタイプで絞り込み:**
```bash
# サブスクリプション関連イベント
stripe events list --limit 20 --type 'customer.subscription.*'

# インボイス関連イベント
stripe events list --limit 20 --type 'invoice.*'
```

**特定イベントの詳細取得:**
```bash
stripe events retrieve evt_xxxxxxxxxxxxx
```

**サブスクリプション作成時に発生するイベント例:**
- `customer.subscription.created` - サブスクリプション作成
- `invoice.created` - インボイス作成
- `invoice.finalized` - インボイス確定
- `invoice.paid` - インボイス支払い完了
- `invoice.payment_succeeded` - 支払い成功
- `invoice.upcoming` - 次回請求予定

各イベントの`pending_webhooks`フィールドで、Webhookエンドポイントへの送信待ち数を確認できます。

## サブスクリプションの作成

### 試用期間付きサブスクリプションの作成
支払い方法が設定されていない顧客でも、試用期間を設定することでサブスクリプションを作成できます。

```bash
stripe subscriptions create \
  -d customer=<customer_id> \
  -d "items[0][price]=<price_id>" \
  -d trial_period_days=7
```

**例:**
```bash
stripe subscriptions create \
  -d customer=cus_TRaf9gfFNUaHIE \
  -d "items[0][price]=price_1SUhJjFQnefyVsT0FIX95e0c" \
  -d trial_period_days=7
```

**結果:**
- ステータス: `trialing`（試用中）
- 試用期間: 7日間
- 試用期間終了後の動作: `create_invoice`（請求書を作成）

## 重要な注意点

### 支払い方法の追加制限
Stripe CLIからは、セキュリティ上の理由で直接カード番号を使った支払い方法の作成ができません。

**エラーになる操作:**
```bash
# これはエラーになる
stripe payment_methods create \
  -d type=card \
  -d "card[number]=4242424242424242" \
  -d "card[exp_month]=12" \
  -d "card[exp_year]=2026" \
  -d "card[cvc]=123"
```

**エラーメッセージ:**
```
Sending credit card numbers directly to the Stripe API is generally unsafe.
We suggest you use test tokens that map to the test card you are using.
```

### 解決方法
1. **試用期間を設定する**（上記の方法）
2. **Stripeダッシュボードから手動で支払い方法を追加**
3. **実際のアプリケーションではStripe.jsを使用**してフロントエンドから安全に支払い方法を作成

## Tips

### コマンドの引数形式
配列形式のパラメータは `-d` オプションとダブルクォートで囲む必要があります:

```bash
# ✓ 正しい
-d "items[0][price]=price_xxx"

# ✗ 誤り（シェルが角括弧を特殊文字として解釈）
--items[0][price]=price_xxx
```
