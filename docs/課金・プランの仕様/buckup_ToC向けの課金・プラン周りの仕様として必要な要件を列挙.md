# ToC向けの課金・プラン周りの仕様として必要な要件

- ToC向けのサブスクリプションプラン機能を提供する
  - ユーザがプランを契約できるようにする
    - Web（Stripe）での決済に対応する
      - Stripeとの連携基盤を構築する
        - Stripe APIクライアントをバックエンドに実装する
        - Stripe APIキーを環境変数で管理する
        - Stripeの商品・価格情報をセットアップする
      - Checkout Sessionを使った決済フローを実装する
        - プラン選択時にCheckout Session作成APIを呼び出す処理を実装する
        - Checkout SessionのURLをクライアントへ返却する処理を実装する
        - 決済完了後のリダイレクト先URLを設定する
        - 決済キャンセル時のリダイレクト先URLを設定する
      - Stripeからのレスポンス受信処理を実装する
        - 決済完了時のコールバックエンドポイントを実装する
        - セッション情報からサブスクリプションIDを取得する処理を実装する
    - ネイティブアプリ（Apple/Google）での決済に対応する
      - Apple App Store決済に対応する
        - StoreKitとの連携処理をクライアントアプリに実装する
        - App Store Connectで商品情報を登録する
        - App Store Server APIとの連携をバックエンドに実装する
        - App Store Server Notificationsの受信エンドポイントを実装する
      - Google Play決済に対応する
        - Google Play Billing Libraryとの連携処理をクライアントアプリに実装する
        - Google Play Consoleで商品情報を登録する
        - Google Play Developer APIとの連携をバックエンドに実装する
        - Google Play Real-time Developer Notificationsの受信エンドポイントを実装する
      - 各プラットフォーム共通のインターフェースを設計する
        - プラットフォームを抽象化した購入処理のインターフェースを定義する
        - プラットフォームごとの実装クラスを用意する
    - プラン選択からサービス有効化までの購入フローを実装する
      - プラン選択UIを実装する
        - 利用可能なプラン一覧を取得するAPIを実装する
        - プラン情報（名称・価格・機能）を表示するUIコンポーネントを実装する
        - プラン比較表を実装する
      - 購入リクエスト処理を実装する
        - ユーザ認証状態を確認する処理を実装する
        - 選択されたプランの妥当性を検証する処理を実装する
        - プラットフォーム別の購入処理を振り分けるロジックを実装する
      - 決済完了後の処理を実装する
        - レシート検証完了後にサブスクリプション情報をDBに保存する処理を実装する
        - プラン情報とサブスクリプション期限を関連付ける処理を実装する
        - 購入完了レスポンスをクライアントへ返却する処理を実装する
      - サービス有効化処理を実装する
        - 購入完了後にプランに応じた権限付与APIを呼び出す処理を実装する
        - 有効化完了をユーザへ通知するUIを実装する
        - 購入履歴を記録する処理を実装する
    - レシート検証を行い購入の正当性を確認する
      - Stripeのレシート検証を実装する
        - Checkout SessionのIDを受け取る処理を実装する
        - Stripe APIでセッション情報を取得する処理を実装する
        - セッションのステータス（完了・キャンセル）を確認する処理を実装する
        - サブスクリプション情報を抽出する処理を実装する
      - Apple App Storeのレシート検証を実装する
        - クライアントからレシートデータを受け取る処理を実装する
        - App Store Server APIのレシート検証エンドポイントを呼び出す処理を実装する
        - 検証レスポンスのステータスコードを確認する処理を実装する
        - トランザクション情報を抽出する処理を実装する
      - Google Playのレシート検証を実装する
        - クライアントから購入トークンを受け取る処理を実装する
        - Google Play Developer APIのレシート検証エンドポイントを呼び出す処理を実装する
        - 購入状態（購入済み・キャンセル済み等）を確認する処理を実装する
        - サブスクリプション情報を抽出する処理を実装する
      - 検証失敗時のエラーハンドリングを実装する
        - ネットワークエラー時のリトライ処理を実装する
        - 検証失敗時のエラーレスポンスを返却する処理を実装する
        - 不正なレシートを検出した場合のログ記録処理を実装する
        - 検証失敗時の管理者通知処理を実装する
  - ユーザの利用権限を正確に管理できるようにする
    - 機能へのアクセス権限を管理する（OpenFGA活用）
      - OpenFGAによる認可チェックを実装する
        - OpenFGAのエンドポイントを既存の認可基盤から利用する
        - 機能アクセス時にOpenFGAへ認可チェックリクエストを送信する処理を実装する
        - 認可チェック結果に基づいてアクセス可否を判定する処理を実装する
      - OpenFGAへの権限データ登録を実装する
        - ユーザと機能の関係性をOpenFGAのタプルとして登録する処理を実装する
        - 権限付与時にタプルを追加する処理を実装する
        - 権限剥奪時にタプルを削除する処理を実装する
    - 利用回数制限を管理する（カウント機構）
      - 利用回数データを保存する基盤を構築する
        - 利用回数を保持するDynamoDBテーブルを設計する
          - ユーザID、リソースID、カウント値、期間種別（日次/月次）、リセット基準日時を含むスキーマを定義する
          - パーティションキーとソートキーを適切に設計する
          - TTLを設定し古いデータを自動削除する仕組みを実装する
        - DynamoDBテーブルをCDKで構築する
          - テーブルリソースを定義する
          - 必要なインデックスを設定する
          - 適切なキャパシティモードを設定する
      - 利用回数のカウント処理を実装する
        - カウントを増減させるLambda関数を実装する
          - リクエストからユーザIDとリソースIDを取得する処理を実装する
          - DynamoDBのアトミックカウンタで+1する処理を実装する
          - カウント失敗時のエラーハンドリングを実装する
        - カウント増加のAPIエンドポイントを実装する
          - API Gatewayでエンドポイントを定義する
          - Lambda関数を統合する
          - 認証・認可を設定する
      - 利用回数制限の判定処理を実装する
        - 現在のカウント値を取得するLambda関数を実装する
          - DynamoDBから該当レコードを取得する処理を実装する
          - レコードが存在しない場合の初期化処理を実装する
        - 上限値と比較して利用可否を判定するLambda関数を実装する
          - 現在のカウント値を取得する処理を実装する
          - プランごとの上限値を取得する処理を実装する
          - カウント値と上限値を比較する処理を実装する
          - 判定結果（可/不可）を返却する処理を実装する
        - 回数制限チェックのAPIエンドポイントを実装する
          - API Gatewayでエンドポイントを定義する
          - Lambda関数を統合する
          - 認証・認可を設定する
      - 利用状況を取得できるようにする
        - ユーザの現在の利用回数を取得するAPIエンドポイントを実装する
          - ユーザIDとリソースIDを指定して利用回数を取得する処理を実装する
          - 上限値と現在値の両方を返却する処理を実装する
          - 複数リソースの利用状況を一括取得できる処理を実装する
    - 権限の付与と剥奪を制御できるAPIを提供する
      - 権限付与APIを実装する
        - 権限付与リクエストを受け付けるLambda関数を実装する
          - ユーザID、機能リスト、回数制限情報を受け取る処理を実装する
          - 付与内容の妥当性を検証する処理を実装する
          - 付与に一意のIDを割り当てる処理を実装する
        - OpenFGAへの権限登録処理を実装する
          - 機能ごとにOpenFGAのタプルを作成する処理を実装する
          - タプルをバルクで登録する処理を実装する
        - 回数制限情報の登録処理を実装する
          - DynamoDBに回数制限の初期レコードを作成する処理を実装する
          - リソースごとの上限値を設定する処理を実装する
          - 期間種別（日次/月次）を設定する処理を実装する
        - 権限付与履歴を記録する処理を実装する
          - 付与ID、ユーザID、付与内容、付与日時をDBに保存する処理を実装する
          - 付与の実行者情報を記録する処理を実装する
        - 権限付与APIエンドポイントを公開する
          - API Gatewayでエンドポイントを定義する
          - Lambda関数を統合する
          - 管理者のみがアクセスできるよう認可を設定する
      - 権限剥奪APIを実装する
        - 権限剥奪リクエストを受け付けるLambda関数を実装する
          - 付与IDを受け取る処理を実装する
          - 付与IDから対象ユーザと権限内容を取得する処理を実装する
          - 剥奪の妥当性を検証する処理を実装する
        - OpenFGAからの権限削除処理を実装する
          - 該当する全てのタプルを特定する処理を実装する
          - タプルをバルクで削除する処理を実装する
        - 回数制限情報の無効化処理を実装する
          - DynamoDBの該当レコードを削除または無効化する処理を実装する
          - 無効化日時を記録する処理を実装する
        - 権限剥奪履歴を記録する処理を実装する
          - 付与ID、剥奪日時、剥奪理由をDBに保存する処理を実装する
          - 剥奪の実行者情報を記録する処理を実装する
        - 権限剥奪APIエンドポイントを公開する
          - API Gatewayでエンドポイントを定義する
          - Lambda関数を統合する
          - 管理者のみがアクセスできるよう認可を設定する
    - 回数制限のリセット処理を実装する（日次・月次）
      - リセットタイミングを決定する
        - 日次リセットの基準時刻を決める（例: 00:00 UTC）
        - 月次リセットの基準日を決める（例: 毎月1日 00:00 UTC）
      - 定期実行の仕組みを構築する
        - 日次リセット用のEventBridge Ruleを作成する
          - cron式で毎日の実行スケジュールを定義する
          - Lambda関数をターゲットに設定する
        - 月次リセット用のEventBridge Ruleを作成する
          - cron式で毎月の実行スケジュールを定義する
          - Lambda関数をターゲットに設定する
      - リセット処理のLambda関数を実装する
        - 日次リセット対象のレコードを特定する処理を実装する
          - DynamoDBから期間種別が「日次」のレコードを取得する処理を実装する
          - リセット対象を絞り込む処理を実装する
        - 月次リセット対象のレコードを特定する処理を実装する
          - DynamoDBから期間種別が「月次」のレコードを取得する処理を実装する
          - リセット対象を絞り込む処理を実装する
        - カウント値をリセットする処理を実装する
          - 対象レコードのカウント値を0に更新する処理を実装する
          - リセット基準日時を更新する処理を実装する
          - バッチ処理で効率的に更新する処理を実装する
        - リセット処理の結果をログ記録する処理を実装する
          - リセット実行日時を記録する処理を実装する
          - リセットしたレコード数を記録する処理を実装する
          - エラー発生時の詳細を記録する処理を実装する
      - リセット処理の監視とエラーハンドリングを実装する
        - リセット処理失敗時のリトライ機構を実装する
          - Lambda関数の失敗をSQSのDLQで捕捉する設定を行う
          - DLQからのリトライ処理を実装する
        - リセット処理失敗時のアラート通知を実装する
          - CloudWatch Alarmを設定する
          - SNSトピックで管理者へ通知する設定を行う
  - 課金プラットフォームからのイベントを処理できるようにする
    - Webhookで各プラットフォームのイベントを受信する
      - Stripe Webhookエンドポイントを実装する
        - Webhook受信用のAPI Gatewayエンドポイントを作成する
        - Webhook処理用のLambda関数を実装する
        - StripeのWebhook署名検証処理を実装する
          - リクエストヘッダーから署名を取得する処理を実装する
          - Stripeの署名検証ライブラリを使用して検証する処理を実装する
          - 署名検証失敗時に400エラーを返す処理を実装する
        - Stripe Webhook secretを環境変数で管理する
        - Stripe管理画面でWebhook URLを登録する
      - Apple App Store Server Notificationsエンドポイントを実装する
        - Webhook受信用のAPI Gatewayエンドポイントを作成する
        - Webhook処理用のLambda関数を実装する
        - AppleのWebhook署名検証処理を実装する
          - JWS形式のペイロードを検証する処理を実装する
          - Appleの公開鍵を使用して署名を検証する処理を実装する
          - 署名検証失敗時に400エラーを返す処理を実装する
        - App Store Connectの共有シークレットを環境変数で管理する
        - App Store ConnectでWebhook URLを登録する
      - Google Play Real-time Developer Notificationsエンドポイントを実装する
        - Webhook受信用のAPI Gatewayエンドポイントを作成する
        - Webhook処理用のLambda関数を実装する
        - GoogleのWebhook署名検証処理を実装する
          - Pub/Subメッセージの検証処理を実装する
          - Google Cloud Pub/Subの認証情報を設定する処理を実装する
          - 署名検証失敗時に400エラーを返す処理を実装する
        - Google Play Console認証情報を環境変数で管理する
        - Google Play ConsoleでWebhook URLを登録する
      - Webhookイベントのログを記録する
        - 受信したイベント全体をDynamoDBに保存する処理を実装する
          - イベントID、プラットフォーム種別、イベント種別、受信日時、ペイロード全体を保存する処理を実装する
          - イベントログテーブルのスキーマを定義する
          - イベントログテーブルをCDKで構築する
        - CloudWatch Logsへ詳細ログを出力する処理を実装する
        - エラー発生時のログレベルを適切に設定する処理を実装する
    - サブスクリプションの期限更新を処理する
      - Stripeの更新成功イベントを処理する
        - invoice.payment_succeededイベントを処理する
          - イベントペイロードからサブスクリプションIDを取得する処理を実装する
          - サブスクリプションIDからユーザIDを特定する処理を実装する
          - 新しい期限（current_period_end）を取得する処理を実装する
          - DBのサブスクリプション期限を更新する処理を実装する
        - customer.subscription.updatedイベントを処理する
          - イベントペイロードから更新内容を取得する処理を実装する
          - プラン変更の有無を確認する処理を実装する
          - 期限変更の有無を確認する処理を実装する
          - DBのサブスクリプション情報を更新する処理を実装する
        - 支払い履歴を記録する処理を実装する
          - 支払い金額、支払い日時、請求書IDをDBに保存する処理を実装する
          - 支払い履歴テーブルのスキーマを定義する
          - 支払い履歴テーブルをCDKで構築する
        - ユーザへ更新完了通知を送信する処理を実装する
          - 通知サービスへ更新完了イベントを送信する処理を実装する
          - 通知テンプレートを用意する
      - Appleの更新成功イベントを処理する
        - DID_RENEWイベントを処理する
          - イベントペイロードからトランザクションIDを取得する処理を実装する
          - トランザクション情報からユーザIDを特定する処理を実装する
          - 新しい期限（expiresDate）を取得する処理を実装する
          - DBのサブスクリプション期限を更新する処理を実装する
        - 支払い履歴を記録する処理を実装する
        - ユーザへ更新完了通知を送信する処理を実装する
      - Googleの更新成功イベントを処理する
        - SUBSCRIPTION_RENEWEDイベントを処理する
          - イベントペイロードから購入トークンを取得する処理を実装する
          - 購入トークンからユーザIDを特定する処理を実装する
          - Google Play Developer APIで最新情報を取得する処理を実装する
          - 新しい期限（expiryTimeMillis）を取得する処理を実装する
          - DBのサブスクリプション期限を更新する処理を実装する
        - 支払い履歴を記録する処理を実装する
        - ユーザへ更新完了通知を送信する処理を実装する
    - 支払い失敗・キャンセル・返金イベントに対応する
      - 支払い失敗イベントを処理する
        - Stripeの支払い失敗イベントを処理する
          - invoice.payment_failedイベントを処理する
            - イベントペイロードから失敗理由を取得する処理を実装する
            - サブスクリプションステータスを「猶予期間」に更新する処理を実装する
            - 次回リトライ日時を取得する処理を実装する
            - DBに失敗情報を記録する処理を実装する
          - ユーザへリトライ通知を送信する処理を実装する
            - 支払い方法の更新を促す通知を送信する処理を実装する
            - 通知テンプレートを用意する
          - リトライスケジュールを設定する処理を実装する
            - EventBridge Ruleでリトライタイミングを設定する処理を実装する
            - リトライ回数の上限を設定する処理を実装する
        - Appleの支払い失敗イベントを処理する
          - DID_FAIL_TO_RENEWイベントを処理する
            - サブスクリプションステータスを「猶予期間」に更新する処理を実装する
            - DBに失敗情報を記録する処理を実装する
          - ユーザへリトライ通知を送信する処理を実装する
        - Googleの支払い失敗イベントを処理する
          - SUBSCRIPTION_IN_GRACE_PERIODイベントを処理する
            - サブスクリプションステータスを「猶予期間」に更新する処理を実装する
            - DBに失敗情報を記録する処理を実装する
          - ユーザへリトライ通知を送信する処理を実装する
        - 猶予期間後のサービス停止処理を実装する
          - 猶予期間終了を検知する処理を実装する
          - サブスクリプションステータスを「無効」に更新する処理を実装する
          - ユーザ権限を剥奪する処理を実装する
          - サービス停止通知を送信する処理を実装する
      - キャンセルイベントを処理する
        - Stripeのキャンセルイベントを処理する
          - customer.subscription.deletedイベントを処理する
            - キャンセル理由（ユーザ都合/支払い失敗）を取得する処理を実装する
            - サブスクリプションステータスを「キャンセル済み」に更新する処理を実装する
            - キャンセル日時を記録する処理を実装する
            - 有効期限までサービス継続可否を判定する処理を実装する
          - ユーザへキャンセル確認通知を送信する処理を実装する
            - 通知テンプレートを用意する
            - サービス終了日を通知に含める処理を実装する
