## 検証実施日時
2025年11月18日 JST

## 検証目的
DynamoDBの重複チェック処理を`GetItemCommand`から`QueryCommand`に修正後、サブスクリプション新規作成イベントが正常に処理されることを確認する。

## 前回の問題
- DynamoDBテーブルは複合キー（`event_id` + `received_at`）を使用
- `findByEventId`メソッドは`GetItemCommand`を使用し、`event_id`のみを指定
- そのため、`ValidationException: The provided key element does not match the schema`エラーが発生
- 重複チェック処理でエラーが発生し、以降の処理（イベント保存、EventBridge送信）が実行されない

## 実施した修正
[webhookEventRepository.ts:34-51](../../../packages/cdk/lambda/billing/payment-gateway/repositories/webhookEventRepository.ts#L34-L51)を修正：
```typescript
// 修正前
async findByEventId(eventId: string): Promise<WebhookEvent | null> {
  const command = new GetItemCommand({
    TableName: this.tableName,
    Key: marshall({ event_id: eventId }),
  });
  // ...
}

// 修正後
async findByEventId(eventId: string): Promise<WebhookEvent | null> {
  const command = new QueryCommand({
    TableName: this.tableName,
    KeyConditionExpression: 'event_id = :event_id',
    ExpressionAttributeValues: marshall({
      ':event_id': eventId,
    }),
    Limit: 1,
  });
  // ...
}
```

### 4. IAMポリシーの確認

```typescript
[
  receiveStripeWebhookFunction,
  receiveAppleNotificationFunction,
  receiveGoogleNotificationFunction,

  func.addToRolePolicy(
    new PolicyStatement({
      effect: Effect.ALLOW,
      actions: ['dynamodb:GetItem', 'dynamodb:PutItem'],  // ← Queryがない
      resources: [
        'arn:aws:dynamodb:*:*:table/*-payment-gateway-webhook-events',

  // ...

```

**問題の特定:**
- Lambda関数には`dynamodb:GetItem`と`dynamodb:PutItem`の権限のみが付与されている
- `QueryCommand`を使用するために必要な`dynamodb:Query`権限が欠けている
- そのため、`findByEventId`メソッドの実行時に`AccessDeniedException`が発生

**判定:** ❌ IAMポリシーに`dynamodb:Query`権限が欠けている

## 次のステップ（修正が必要な項目）

### 修正内容

[payment-gateway.ts:186-199](../../../packages/cdk/lib/construct/api/payment-gateway.ts#L186-L199)のIAMポリシーに`dynamodb:Query`権限を追加：

```typescript
// 修正前
func.addToRolePolicy(
  new PolicyStatement({
    effect: Effect.ALLOW,
    actions: ['dynamodb:GetItem', 'dynamodb:PutItem'],
    resources: [
      'arn:aws:dynamodb:*:*:table/*-payment-gateway-webhook-events',
    ],
  })
);

// 修正後
func.addToRolePolicy(
  new PolicyStatement({
    effect: Effect.ALLOW,
    actions: ['dynamodb:GetItem', 'dynamodb:PutItem', 'dynamodb:Query'],
    resources: [
      'arn:aws:dynamodb:*:*:table/*-payment-gateway-webhook-events',
    ],
  })
);
```

### 修正理由

- `findByEventId`メソッドが`QueryCommand`を使用するようになったため、`dynamodb:Query`権限が必要
- 複合キーテーブルでパーティションキーのみで検索する場合は`Query`操作を使用する必要がある
