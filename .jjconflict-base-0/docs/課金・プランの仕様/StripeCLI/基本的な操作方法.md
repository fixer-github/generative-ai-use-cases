## データの読み取り操作

### 商品一覧の取得
```bash
stripe products list --limit 5
```

### 価格一覧の取得
```bash
stripe prices list --limit 5
```

### 顧客一覧の取得
```bash
stripe customers list --limit 5
```

### サブスクリプション一覧の取得
```bash
stripe subscriptions list --limit 5
```

### イベント履歴の取得
Stripe上で発生したイベント（Webhook送信対象）の履歴を確認できます。

**全イベントの取得:**
```bash
stripe events list --limit 10
```

**特定のイベントタイプで絞り込み:**
```bash
# サブスクリプション関連イベント
stripe events list --limit 20 --type 'customer.subscription.*'

# インボイス関連イベント
stripe events list --limit 20 --type 'invoice.*'
```

**特定イベントの詳細取得:**
```bash
stripe events retrieve evt_xxxxxxxxxxxxx
```

**サブスクリプション作成時に発生するイベント例:**
- `customer.subscription.created` - サブスクリプション作成
- `invoice.created` - インボイス作成
- `invoice.finalized` - インボイス確定
- `invoice.paid` - インボイス支払い完了
- `invoice.payment_succeeded` - 支払い成功
- `invoice.upcoming` - 次回請求予定

各イベントの`pending_webhooks`フィールドで、Webhookエンドポイントへの送信待ち数を確認できます。

## サブスクリプションの作成

### 試用期間付きサブスクリプションの作成
支払い方法が設定されていない顧客でも、試用期間を設定することでサブスクリプションを作成できます。

```bash
stripe subscriptions create \
  -d customer=<customer_id> \
  -d "items[0][price]=<price_id>" \
  -d trial_period_days=7
```

**例:**
```bash
stripe subscriptions create \
  -d customer=cus_TRaf9gfFNUaHIE \
  -d "items[0][price]=price_1SUhJjFQnefyVsT0FIX95e0c" \
  -d trial_period_days=7
```

**結果:**
- ステータス: `trialing`（試用中）
- 試用期間: 7日間
- 試用期間終了後の動作: `create_invoice`（請求書を作成）

## サブスクリプションのキャンセル

### 基本的なキャンセル方法
```bash
stripe subscriptions cancel <subscription_id> -c
```

`-c`オプションを付けることで確認プロンプトをスキップできます。

**例:**
```bash
stripe subscriptions cancel sub_1SUioYFQnefyVsT0MJSsFA5l -c
```

**結果:**
- ステータス: `canceled`
- `canceled_at`: キャンセル日時のタイムスタンプ
- `ended_at`: サブスクリプション終了日時のタイムスタンプ
- `cancellation_details.reason`: `cancellation_requested`

**注意点:**
- キャンセルされたサブスクリプションは`stripe subscriptions list`では表示されなくなります
- キャンセル後も、サブスクリプションIDを指定すれば`stripe subscriptions retrieve <subscription_id>`で詳細を取得できます

## 重要な注意点

### 支払い方法の追加制限
Stripe CLIからは、セキュリティ上の理由で直接カード番号を使った支払い方法の作成ができません。

**エラーになる操作:**
```bash
# これはエラーになる
stripe payment_methods create \
  -d type=card \
  -d "card[number]=4242424242424242" \
  -d "card[exp_month]=12" \
  -d "card[exp_year]=2026" \
  -d "card[cvc]=123"
```

**エラーメッセージ:**
```
Sending credit card numbers directly to the Stripe API is generally unsafe.
We suggest you use test tokens that map to the test card you are using.
```

### 解決方法
1. **試用期間を設定する**（上記の方法）
2. **Stripeダッシュボードから手動で支払い方法を追加**
3. **実際のアプリケーションではStripe.jsを使用**してフロントエンドから安全に支払い方法を作成

## Webhookイベントのトリガー

### Webhookイベントを手動でトリガーする
テスト環境でWebhookの動作を確認したい場合、Stripe CLIの`trigger`コマンドを使用してイベントを手動で発生させることができます。

```bash
# サブスクリプション作成イベントをトリガー
stripe trigger customer.subscription.created

# サブスクリプション更新イベントをトリガー
stripe trigger customer.subscription.updated

# 支払い成功イベントをトリガー
stripe trigger invoice.payment_succeeded

# 支払い失敗イベントをトリガー
stripe trigger invoice.payment_failed
```

### ローカルでWebhookをリッスンする
ローカル開発環境でWebhookを受信する場合、Stripe CLIの`listen`コマンドを使用します。

```bash
# デフォルトポート（localhost:4242）でリッスン
stripe listen --forward-to localhost:4242/webhook

# カスタムポートでリッスン
stripe listen --forward-to localhost:3000/api/webhook/stripe

# 特定のイベントのみをリッスン
stripe listen --forward-to localhost:4242/webhook \
  --events customer.subscription.created,customer.subscription.updated,invoice.payment_succeeded
```

**注意点**:
- `stripe listen`を実行すると、Webhook署名シークレットが表示されます。このシークレットを環境変数に設定する必要があります。
- ローカル開発時のみ使用してください。本番環境ではStripe Dashboardから設定したWebhook URLを使用します。

## Tips

### コマンドの引数形式
配列形式のパラメータは `-d` オプションとダブルクォートで囲む必要があります:

```bash
# ✓ 正しい
-d "items[0][price]=price_xxx"

# ✗ 誤り（シェルが角括弧を特殊文字として解釈）
--items[0][price]=price_xxx
```

### Webhookシークレットの確認
Webhookエンドポイントの署名検証に必要なシークレットを確認します。

```bash
# Webhook エンドポイント一覧を取得
stripe webhook_endpoints list

# 特定のWebhookエンドポイントの詳細を取得
stripe webhook_endpoints retrieve we_xxxxxxxxxxxxx
```

**注意**: Webhook secretは一度しか表示されません。紛失した場合は、新しいエンドポイントを作成する必要があります。

### JSON形式での出力
CLIの出力をJSON形式で取得し、jqでパースすることができます。

```bash
# 顧客情報をJSON形式で取得
stripe customers retrieve cus_xxxxxxxxxxxxx --format json | jq .

# サブスクリプション一覧をJSON形式で取得し、IDのみを抽出
stripe subscriptions list --limit 10 --format json | jq '.data[].id'

# 特定のフィールドのみを抽出
stripe subscriptions retrieve sub_xxxxxxxxxxxxx --format json | \
  jq '{id: .id, status: .status, current_period_end: .current_period_end}'
```
